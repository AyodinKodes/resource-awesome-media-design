## Coding

### Code editors and IDEs

- [Android Studio](https://developer.android.com/studio) - IDE for Android apps.
- [IntelliJ IDEA](https://www.jetbrains.com/idea/) - IDE for Java and Kotlin.
- [PyCharm](https://www.jetbrains.com/pycharm/) - IDE for Python.
- [Visual Studio Code](https://code.visualstudio.com/) - Code editor with many extensions.

### Notebooks

- [Jupyter](https://jupyter.org/) - Notebooks that mix code, text and results.

### Creative coding

- [openFrameworks](https://openframeworks.cc/) - C++ toolkit for creative coding.
- [p5.js](https://p5js.org/) - JavaScript library for creative coding in the browser.
- [Processing](https://processing.org/) - Sketchbook and language for the visual arts.

### Terminal

- [Ghostty](https://ghostty.org/) - GPU-accelerated terminal app.
- [Homebrew](https://brew.sh/) - Package manager for macOS.
- [tldr](https://tldr.sh/) - Short examples for terminal commands.
- [tmux](https://github.com/tmux/tmux/wiki) - Terminal multiplexer with windows and panes.

### Version control

- [Git](https://git-scm.com/) - Version control system.
- [GitHub](https://github.com/) - Platform to host code and work together.
- [GitLab](https://about.gitlab.com/) - Platform to host code and work together, which you can also host yourself.

### Command-line tools

- [cowsay](https://cowsay.diamonds/) - Cow that says your text.
- [FFmpeg](https://ffmpeg.org/) - Tool to convert video and audio.
- [FIGlet](https://www.figlet.org/) - Tool that makes large letters from text.
- [ImageMagick](https://imagemagick.org/) - Tool to resize and convert images.
- [Pandoc](https://pandoc.org/) - Document converter for Markdown, Word, HTML and more.
- [Wget](https://www.gnu.org/software/wget/) - Tool to download files from a URL.
- [yt-dlp](https://github.com/yt-dlp/yt-dlp) - Tool to download video and audio from web pages.

### JavaScript

- [Node.js](https://nodejs.org/) - Runtime for JavaScript outside the browser.
- [nvm](https://github.com/nvm-sh/nvm) - Version manager for Node.js.

## Real time

### 3D on the web

- [Three.js](https://threejs.org/) - JavaScript library for 3D in the browser.

### Node-based

- [TouchDesigner](https://derivative.ca/) - Node-based environment for real-time visuals, free for non-commercial use.

- [The Book of Shaders](https://thebookofshaders.com/) - Step-by-step guide to fragment shaders.

### Live coding

- [P5 Live](https://teddavis.org/p5live/) - Live coding environment for p5.js.

### Projection mapping

- [MadMapper](https://madmapper.com/) - Software for projection mapping and LED mapping.
- [Resolume](https://resolume.com/) - VJ software with projection mapping.

## Graphics

### Raster and painting

- [GIMP](https://www.gimp.org/) - Free and open-source image editor, an alternative to Photoshop.
- [ibis Paint X](https://ibispaint.com/) - Drawing app for phones and tablets.
- [Photoshop](https://www.adobe.com/products/photoshop.html) - Image editor by Adobe.
- [Procreate](https://procreate.com/) - Drawing app for iPad.

### Vector

- [Affinity](https://www.affinity.studio/) - Free design app for vector, photo and layout.
- [Illustrator](https://www.adobe.com/products/illustrator.html) - Vector graphics editor by Adobe.
- [Vector Halftone Maker](https://halftone.xoihazard.com/) - Halftone pattern generator with PNG and SVG export.

### Generative tools

- [antlii.work](https://antlii.work/) - Generative art tools in the browser.
- [tooooools.app](https://www.tooooools.app/) - Image and video effects, such as dithering, stippling and ASCII.

## 3D

### Modelling and rendering

- [Blender](https://www.blender.org/) - Free and open-source 3D modelling, animation and rendering.
- [Cinema 4D](https://www.maxon.net/cinema-4d) - 3D modelling and animation, popular for motion design.
- [Houdini](https://www.sidefx.com/products/houdini/) - Procedural 3D and visual effects, with a free learning version.
- [Maya](https://www.autodesk.com/products/maya/overview) - 3D modelling and animation for film and games.
- [SketchUp](https://sketchup.trimble.com/) - Simple 3D modelling for architecture and design.

### Viewers

- [noclip.website](https://noclip.website/) - Viewer for video game levels in the browser.

## Game engines

- [Bitsy](https://bitsy.org/) - Free editor for small pixel games.
- [Godot](https://godotengine.org/) - Free and open-source game engine.
- [Twine](https://twinery.org/) - Free and open-source tool for interactive stories.
- [Unity](https://unity.com/) - Game engine for 2D, 3D and XR.
- [Unreal Engine](https://www.unrealengine.com/) - Game engine with high-end 3D graphics.
