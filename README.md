## Coding

### Code editors and IDEs

- [Android Studio](https://developer.android.com/studio) - Free IDE for Android apps.
- [IntelliJ IDEA](https://www.jetbrains.com/idea/) - Freemium IDE for Java and Kotlin.
- [PyCharm](https://www.jetbrains.com/pycharm/) - Freemium IDE for Python.
- [Visual Studio Code](https://code.visualstudio.com/) - Free code editor with many extensions.

### Notebooks

- [Jupyter](https://jupyter.org/) - Open-source notebooks that mix code, text and results.

### Creative coding

- [openFrameworks](https://openframeworks.cc/) - Open-source C++ toolkit for creative coding.
- [p5.js](https://p5js.org/) - Open-source JavaScript library for creative coding in the browser.
- [Processing](https://processing.org/) - Open-source sketchbook and language for the visual arts.

### Terminal

- [Ghostty](https://ghostty.org/) - Open-source terminal app.
- [Homebrew](https://brew.sh/) - Open-source package manager for macOS.
- [tldr](https://tldr.sh/) - Open-source short examples for terminal commands.
- [tmux](https://github.com/tmux/tmux/wiki) - Open-source terminal multiplexer.

### Version control

- [Git](https://git-scm.com/) - Open-source version control system.
- [GitHub](https://github.com/) - Freemium platform to host code and work together.
- [GitLab](https://about.gitlab.com/) - Freemium platform to host code and work together.

### Command-line tools

- [cowsay](https://cowsay.diamonds/) - Open-source cow that says your text.
- [FFmpeg](https://ffmpeg.org/) - Open-source tool to convert video and audio.
- [FIGlet](https://www.figlet.org/) - Open-source tool that makes large letters from text.
- [ImageMagick](https://imagemagick.org/) - Open-source tool to resize and convert images.
- [Pandoc](https://pandoc.org/) - Open-source document converter for Markdown, Word, HTML and more.
- [Wget](https://www.gnu.org/software/wget/) - Open-source tool to download files from a URL.
- [yt-dlp](https://github.com/yt-dlp/yt-dlp) - Open-source tool to download video and audio from web pages.

### JavaScript

- [Node.js](https://nodejs.org/) - Open-source runtime for JavaScript outside the browser.
- [nvm](https://github.com/nvm-sh/nvm) - Open-source version manager for Node.js.
